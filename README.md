# TradingApp
An interactive financial markets application built in R and Shiny, designed to combine market analysis, portfolio management, quantitative finance, and trading strategies in a single platform.

The application allows users to analyze financial assets and portfolios using historical market data, technical indicators, trading signals, and backtesting. It also incorporates portfolio risk and performance analysis, volatility estimation, VaR and CVaR, correlation analysis, efficient frontier optimization, machine learning models with walk-forward validation, Monte Carlo simulations, Black-Litterman portfolio optimization, and pairs trading strategies.

The project was developed to apply quantitative finance and econometric concepts in a practical fintech environment, integrating financial theory, statistical analysis, programming, and interactive data visualization.
